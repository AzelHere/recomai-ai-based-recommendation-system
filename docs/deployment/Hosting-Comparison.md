# Hosting comparison
Checked 25 November 2026 against the linked primary provider pages. No resources were purchased or provisioned. Estimates below are recommendations, not measured production capacity. Allow roughly 4 GB RAM and 40–80 GB SSD for a small single-instance app, MySQL, proxy, updates and backup headroom; build elsewhere if necessary. Do not store scanner databases indefinitely on a small production host.

| Option | Java / Docker / MySQL | Persistence and HTTPS | Cost and limits | Backup / complexity |
|---|---|---|---|---|
| University Linux server | Confirm Java 21 or Docker Engine + Compose availability with IT; MySQL can run in Compose | Persistent institution disk and approved DNS/TLS required | Institution-specific, not assumed free; request 4 GB RAM and 40 GB SSD | Ask IT about snapshots, encrypted off-host storage and access policy; simplest budget choice if allocated |
| DigitalOcean Basic VPS | Docker permits the existing Java image and MySQL container | Local SSD persists; operator configures HTTPS | Official page lists $12/month for 2 GiB/50 GiB and $24/month for 4 GiB/80 GiB; 4 GiB is the recommended starting estimate. Domain, tax and external storage may add cost | Operator-managed MySQL backups; provider backups cost extra; moderate Linux administration |
| Hetzner cost-optimized VPS | Compatible x86 Linux Docker deployment | Persistent SSD; operator-managed TLS | CX23 lists 2 vCPU, 4 GB and 40 GB, but is currently unavailable on the checked official page. Dynamic pricing did not render reliably, so no guaranteed purchasable price is quoted | Recheck regional availability and current checkout total; operator must manage database backups |
| Render Docker services | Java Docker service plus a separate paid private MySQL service | MySQL requires paid persistent disk; platform handles public service TLS | Not an all-free deployment. App compute, database compute and disk are separate charges; obtain a complete current quote | More conversion from Compose; use logical database backups, not raw disk snapshot restoration |

Recommendation: use an approved university server for the assessment if available. For a later small paid public launch, one 4 GiB Linux VPS preserves Compose and keeps the architecture understandable. DigitalOcean's published $24/month VM is a clear budgeting reference, not a purchase recommendation independent of the user's budget. Avoid the 512 MiB/1 GiB tiers for an unmeasured app+MySQL stack. Public launch still requires the release gates, consent and content-rights review.

Sources: [DigitalOcean official pricing](https://www.digitalocean.com/pricing/droplets), [Hetzner current availability](https://www.hetzner.com/cloud/cost-optimized/), [Render MySQL deployment](https://render.com/docs/deploy-mysql), [Render disk constraints](https://render.com/docs/disks), [Render pricing](https://render.com/pricing). Recheck prices at purchase time.
