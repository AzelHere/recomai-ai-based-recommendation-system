# Recom AI release preparation
Proposed version: v2.0.0. Release title: Recom AI explainable learning workspace. This is a release draft; no Git commit, tag, push or publication has occurred. The current Maven artifact remains 0.1.0-SNAPSHOT; a release naming change must be reviewed separately rather than falsely claiming an existing Git tag.

Implemented: session accounts/onboarding, preference and feedback aware resource ranking, genuine metadata provenance and bounded ingestion, Saved/collections/explicit progress/activity, persistent learning journeys, profile/settings/account export/delete, admin catalog pagination/settings/analytics and responsive Premium Graphite frontend with optional Three.js. Phase 4 hardened source fetching, cache invalidation, safe error/logging, same-origin mutations and guarded URL repairs. Phase 5 completes the container scan, pins the runtime base digest, updates the available perl-base security patch and removes unused vulnerable pebble from the image. Stack remains Java 21, Spring MVC/JDBC, MySQL/Flyway, HTML/CSS/JS and Three.js.

Known limits: residual Medium/Low OS advisories, small locally measured capacity, sparse collaborative evidence, process-local sessions/rate/cache state, source metadata gaps, time-sensitive external links, assistant-assigned catalog judgments, and noncommercial/share-alike catalog restrictions. No universal accuracy or public deployment approval is claimed. See the final facts manifest and security report for current exact findings and test outcomes.

Installation: review README and Deployment-Guide.md; configure private environment values; start existing images with docker compose up -d, build only after code/image changes. Fresh deployments start with 200 curated resources; acquire/review/import the genuine metadata through the operator pipeline. Public hosting requires HTTPS/SMTP/admin/secrets/backups and explicit owner approval.
