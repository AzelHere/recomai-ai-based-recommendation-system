# Genuine application screenshots

This directory is reserved for screenshots captured from the running RecomAI application. No screenshots are included yet.

When adding submission screenshots:

1. Run the application and capture the actual browser UI (do not use mockups or generated substitutes).
2. Use synthetic accounts and catalog content where possible.
3. Remove or blur email addresses, reset links/tokens, browser profile details, local file paths, and other personal data.
4. Save optimized PNG or JPEG files here with descriptive names such as `signup.png`, `onboarding.png`, `recommendations.png`, or `admin-catalog.png`.
5. Link each image from the README with a short caption that describes the screen, without claiming untested behavior.

After capturing, add the screenshot files to Git intentionally and review them before publishing. Do not place `.env`, database exports, test traces, or browser profiles in this directory.
